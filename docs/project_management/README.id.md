# 📂 Manajemen Proyek, Peta Jalan & Transfer Pengetahuan

Folder ini berisi dokumentasi manajemen proyek, audit kesesuaian fitur, peta jalan rilis (*release roadmaps*), serta berkas transfer pengetahuan (*knowledge transfer*) antar anggota tim pengembang untuk mempercepat proses *onboarding* developer baru.

---

## 🧭 Panduan & Perbedaan Berkas Dokumen

Dokumentasi di folder ini diklasifikasikan ke dalam beberapa berkas utama yang tersedia dalam versi Bahasa Indonesia (`*.id.md`) dan Bahasa Inggris (`*.md`):

1.  **Daftar Peta Jalan Fitur ([feature_roadmap_checklist.id.md](./feature_roadmap_checklist.id.md)):** 
    Daftar periksa terperinci mengenai status kelayakan seluruh fitur HRMS (Payroll, Presensi, Reimbursement) untuk melacak modul yang siap rilis.
2.  **Transfer Pengetahuan Frontend & Mobile ([knowledge_transfer_frontend_mobile.id.md](./knowledge_transfer_frontend_mobile.id.md)):** 
    Dokumen panduan arsitektur bagi developer frontend dan mobile baru untuk memahami tata letak repositori Next.js, Flutter, cara integrasi REST API, dan manajemen state.
3.  **Audit Fitur Aplikasi Mobile ([mobile_feature_audit.id.md](./mobile_feature_audit.id.md)):** 
    Hasil verifikasi perbandingan kesamaan fitur (*feature parity*) antara aplikasi web Next.js dengan aplikasi mobile Flutter guna mendeteksi modul yang belum setara.
