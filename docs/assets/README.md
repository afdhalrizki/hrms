# 🖼️ Technical Documentation Assets

This directory contains visual assets, including user interface screenshots, system flowcharts, database visualizations, and architectural diagrams embedded across all technical documentation files of the HariKerja HRMS platform.

---

## 🧭 Visual Asset Usage & Guidelines

All assets inside this folder are linked directly in the main markdown documentation files. Key visual assets available include:

*   **Integrated Workflow Diagram ([hrms_integrated_workflow.png](./hrms_integrated_workflow.png)):** Shows end-to-end data interaction from frontend, APIs, message brokers, to Postgres database schemas.
*   **Payroll Flowchart ([payroll_flowchart.png](./payroll_flowchart.png)):** Illustrates payroll calculation flows, admin approvals, and automatic payslip PDF generations.
*   **Premium UI Screenshots:** High-resolution visual guides helping stakeholders and manual testers during UAT sessions.
*   **RBAC Walkthrough ([rbac_walkthrough_proven_1773645692977.webp](./rbac_walkthrough_proven_1773645692977.webp)):** Visual explanation of role-based access controls and database tenant isolation.
