# 📚 Academic Literature & Research References

This folder contains academic reference documents, scientific theses, extracted text references, and extraction utility scripts used as the theoretical and mathematical foundation for designing payroll math, biometric fingerprint configurations, and GPS geofenced attendance calculations on the HariKerja HRMS platform.

---

## 🧭 Document Guide & Parity

Resources in this folder are organized under three core academic studies accompanied by extracted plain text files and an extraction script:

1.  **Case Study 1: STIKOM Surabaya ([15410100038-2018-STIKOMSURABAYA](./15410100038-2018-STIKOMSURABAYA.pdf)):**
    *   [PDF](./15410100038-2018-STIKOMSURABAYA.pdf) & [TXT](./15410100038-2018-STIKOMSURABAYA.txt) files.
    *   Research regarding corporate biometric fingerprint integration and database storage models.
2.  **Case Study 2: STIKOM/Jurnal Magelang ([16.0504.0168_BAB I_ABAB II_BAB III_BAB V_BAB VI_DAFTAR PUSTAKA](./16.0504.0168_BAB%20I_ABAB%20II_BAB%20III_BAB%20V_BAB%20VI_DAFTAR%20PUSTAKA.pdf)):**
    *   [PDF](./16.0504.0168_BAB%20I_ABAB%20II_BAB%20III_BAB%20V_BAB%20VI_DAFTAR%20PUSTAKA.pdf) & [TXT](./16.0504.0168_BAB%20I_ABAB%20II_BAB%20III_BAB%20V_BAB%20VI_DAFTAR%20PUSTAKA.txt) files.
    *   Academic study focusing on payroll work processes, BPJS structure layouts, and PPh 21 employee tax models.
3.  **Case Study 3: Deni Irawan FST ([DENI IRAWAN-FST](./DENI%20IRAWAN-FST.pdf)):**
    *   [PDF](./DENI%20IRAWAN-FST.pdf) & [TXT](./DENI%20IRAWAN-FST.txt) files.
    *   Research addressing secure networks and geofenced attendance math using GPS coordinates.
4.  **Extraction Script ([extract_pdfs.py](./extract_pdfs.py)):**
    *   A helper Python script to automatically convert PDF files into structured plain text files.
